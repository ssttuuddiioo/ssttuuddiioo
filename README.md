# Pablo Gnecco

I build rooms that notice you're in them.

Studio Studio is my practice in Brooklyn — experiential direction, creative
technology, and light. Colombian born. The commercial work funds the artwork,
and the artwork keeps the commercial work honest.

### A few things that live here

Most of this is sketchbook. The finished work is on walls.

**[kinect-mac](https://github.com/ssttuuddiioo/kinect-mac)** — Kinect v2 on Apple
Silicon. Depth, background removal, and point clouds into TouchDesigner, OBS,
anything Syphon. Written because the alternative was buying a Windows machine.

**[luminous-depths](https://github.com/ssttuuddiioo/luminous-depths)** — a WebGL2
fluid solver with a bioluminescent swarm inside it, driven by webcam hand
tracking. MediaPipe landmarks, 1€-filtered, every parameter live-tunable.
→ [try it](https://luminous-depths-coral.vercel.app)

**[dumbowind](https://github.com/ssttuuddiioo/dumbowind)** — *Let Go.* You write
down what you want to be rid of; the words come apart into an ASCII wind field
and leave with the flock. → [try it](https://dumbowind.vercel.app)

**[seed-to-cup-apps](https://github.com/ssttuuddiioo/seed-to-cup-apps)** — open
tools for coffee farmers. De la semilla a la taza.

And [flappysoupy](https://github.com/ssttuuddiioo/flappysoupy), because sometimes
one HTML file is the whole idea.
